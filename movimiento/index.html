Teoría y fórmulas

Las ideas esenciales detrás de cada movimiento.

RESUMEN
MRU

Velocidad constante

La aceleración es cero.

x = x₀ + vt
MRUA

Aceleración constante

La velocidad cambia linealmente.

x = x₀ + v₀t + ½at²
v = v₀ + at
VERTICAL

Movimiento bajo gravedad

Con +y hacia arriba, la aceleración es constante y negativa.

y = y₀ + v₀t − ½gt²
vᵧ = v₀ − gt
PARABÓLICO

Dos movimientos independientes

MRU horizontal y MRUA vertical.

v₀ₓ = v₀ cosθ
v₀ᵧ = v₀ senθ
CIRCULAR

Giro y movimiento lineal

El radio conecta magnitudes angulares y lineales.

v = Rω
ac = Rω²
at = Rα
SIGNOS

¿Frenar o acelerar?

Depende del producto v·a.

v·a < 0 → disminuye rapidez
v·a > 0 → aumenta rapidez
